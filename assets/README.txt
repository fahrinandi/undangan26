ASSETS FOLDER

favicon.svg is used as the browser icon.

The graduates/ folder contains the 14 optimized WebP portraits used by the
opening-page slideshow. Keep the filenames unchanged unless you also update
the corresponding image paths in index.html.

You may add photographs or music here later. If you add them, reference them
from index.html using a relative path, for example:
  assets/foto-bersama.jpg

The graduation-cap decorations are drawn in CSS so no additional decorative
image files are required.
