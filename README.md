# Undangan Wisuda Dokter Spesialis KFR 2026

Paket ini siap diunggah ke repository GitHub Pages.

## Isi paket

- `index.html`: seluruh isi undangan
- `style.css`: warna, tata letak, animasi, dan tampilan responsif
- `script.js`: kolase dua kelompok foto yang bergantian, pembuka undangan, hitung mundur, animasi, dan kalender
- `assets/graduates/`: 14 foto lulusan yang sudah dioptimalkan dalam format WebP

## Cara menerbitkan

1. Unggah semua isi folder ini ke root repository `physiatrist-graduation`.
2. Buka **Settings → Pages** pada repository.
3. Pilih **Deploy from a branch**, branch **main**, folder **/(root)**.
4. Setelah aktif, undangan tersedia di:
   `https://fahrinandi.github.io/physiatrist-graduation/`

## Catatan

Waktu acara belum dicantumkan karena belum diberikan. Untuk menambahkannya,
edit bagian informasi acara di `index.html` dan waktu `eventDate` di `script.js`.
